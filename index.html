Proyecto 2: Plataforma de E-commerce

Una tienda en línea completa con carrito de compras, pasarela de pagos integrada y un panel de administración para gestionar productos. Desarrollada utilizando React, Node.js y MongoDB.

Proyecto 3: Aplicación de Gestión de Tareas

Un organizador de tareas diario que permite a los usuarios crear tableros visuales, asignar prioridades y realizar un seguimiento del progreso mediante gráficos interactivos. Construido con Vue.js y Firebase.

Proyecto 4: Dashboard del Clima

Una aplicación meteorológica que consume una API externa para mostrar el pronóstico del tiempo en tiempo real de cualquier ciudad del mundo, incluyendo mapas interactivos y datos de calidad del aire.

Ver detalles

Proyecto 5: Buscador de Recetas Móvil

Una aplicación móvil híbrida diseñada para los amantes de la cocina. Permite buscar recetas basadas en los ingredientes que ya tienes en casa. Desarrollada con React Native y una base de datos local SQLite.
